# 🖐️ Hand Gesture Volume Control

## 📌 معرفی پروژه

این پروژه یک سیستم هوشمند برای کنترل صدای کامپیوتر با استفاده از حرکات دست و انگشتان است.

در این پروژه با استفاده از دوربین وب‌کم (Webcam) و تکنولوژی پردازش تصویر، تعداد انگشتان دست تشخیص داده می‌شود و بر اساس آن صدای سیستم به‌صورت خودکار افزایش یا کاهش پیدا می‌کند.

این سیستم بدون نیاز به ماوس یا کیبورد امکان کنترل صدا را فراهم می‌کند.

## ✨ امکانات پروژه

- 📷 تشخیص دست از طریق وب‌کم
- 🖐️ تشخیص تعداد انگشتان باز دست
- 🔊 افزایش صدای سیستم با نشان دادن ۳ انگشت
- 🔉 کاهش صدای سیستم با نشان دادن ۲ انگشت
- 📊 نمایش تعداد انگشتان تشخیص داده‌شده روی تصویر
- 🎥 نمایش زنده تصویر دوربین
- ⏱️ جلوگیری از تغییر سریع و ناخواسته صدا با استفاده از تأخیر زمانی
- ⌨️ خروج از برنامه با فشردن کلید Q

## 🛠️ تکنولوژی‌های استفاده‌شده

- Python
- OpenCV
- MediaPipe
- Pycaw
- Time

## ⚙️ پیش‌نیازها

ابتدا Python را نصب کنید.

سپس کتابخانه‌های موردنیاز را نصب نمایید:

```bash
pip install opencv-python mediapipe pycaw comtypes
```

## 🚀 نحوه اجرا

**1. دریافت پروژه از GitHub**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. ورود به پوشه پروژه**

```bash
cd YOUR_PROJECT_NAME
```

**3. نصب کتابخانه‌ها**

```bash
pip install -r requirements.txt
```

**4. اجرای برنامه**

```bash
python main.py
```

**5. استفاده از برنامه**

- دوربین سیستم را فعال کنید.
- دست خود را مقابل دوربین قرار دهید.
- برای افزایش صدا، ۳ انگشت خود را نشان دهید.
- برای کاهش صدا، ۲ انگشت خود را نشان دهید.
- برای خروج از برنامه کلید Q را فشار دهید.

## 🧠 نحوه عملکرد پروژه

1. دوربین وب‌کم تصاویر را به‌صورت زنده دریافت می‌کند.
2. با استفاده از OpenCV تصویر پردازش و آماده تحلیل می‌شود.
3. MediaPipe نقاط کلیدی دست (Hand Landmarks) را شناسایی می‌کند.
4. با بررسی موقعیت نقاط کلیدی انگشتان، تعداد انگشتان باز تشخیص داده می‌شود.
5. اگر ۳ انگشت باز باشد، صدای سیستم افزایش پیدا می‌کند.
6. اگر ۲ انگشت باز باشد، صدای سیستم کاهش پیدا می‌کند.
7. تغییرات صدا با استفاده از کتابخانه Pycaw روی صدای اصلی سیستم اعمال می‌شود.
